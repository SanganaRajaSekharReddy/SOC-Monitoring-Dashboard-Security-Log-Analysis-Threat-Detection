# SOC Monitoring Dashboard – Security Log Analysis & Threat Detection

A Python-based Security Operations Center (SOC) Monitoring Dashboard designed to analyze security logs, identify suspicious login activities, and visualize security events.

This project demonstrates basic SOC Analyst activities, including log collection, security event analysis, threat detection, and incident reporting.

## Features

- **Log Collection:** Import security log data from CSV files.
- **Log Analysis:** Analyze successful and failed login attempts.
- **Threat Detection:** Identify multiple failed login attempts and suspicious users.
- **Security Dashboard:** Visualize login statistics and user activity.
- **Data Visualization:** Generate graphs using Matplotlib.
- **Security Reporting:** Generate incident summaries and recommendations.

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Files
- Streamlit

## Project Objectives

- Understand security log monitoring.
- Identify suspicious login activities.
- Learn basic brute-force attack detection.
- Visualize security events.
- Generate security reports.

## Learning Outcomes

This project provides practical experience in security monitoring, log analysis, threat detection, data visualization, and SOC reporting.
